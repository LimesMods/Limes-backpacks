# Lime's Backpacks

Lime's Backpacks adds six wearable backpacks to Fabric 26.2. Each tier has its own capacity, materials, model details and equipment loadout.

**Download:** [Modrinth](https://modrinth.com/mod/limesbackpacks)

## Supported versions

Each Minecraft version is developed on its own branch.

|---|---|---|---|

Every version also needs [Fabric API](https://modrinth.com/mod/fabric-api).

## Features

- Wearable backpacks with persistent inventories.
- Leather, Copper, Iron, Golden, Diamond and Netherite tiers.
- Capacities of 9, 18, 27, 36, 54 and 81 slots.
- Optional Trinkets support for the chest/back slot. The mod also works without Trinkets.
- Toggleable lanterns on the Diamond and Netherite tiers, with a rebindable **Toggle Backpack Lantern** key.
- Optional LambDynamicLights support for the lanterns, which also works with [Complementary](https://modrinth.com/shader/complementary-unbound) shaders.
- A quiver on the Netherite backpack that supplies arrows to bows and crossbows.
- Crouch right-click placement with hopper interaction, item preservation and tier-specific sounds.
- A dedicated advancement tab with one milestone for each crafted tier.

## Crafting

Start with a Leather Backpack, then upgrade it one tier at a time. Upgrading keeps everything inside the backpack. Bundles and shulker boxes used as ingredients must be empty.

| Tier | Ingredients |
|---|---|
| Leather | 8 Leather + any Bundle |
| Copper | Leather Backpack + 4 Copper Ingots, 2 String, 2 Leather |
| Iron | Copper Backpack + 6 Iron Ingots, 2 Chains |
| Golden | Iron Backpack + 5 Gold Ingots, 3 Green Wool |
| Diamond | Golden Backpack + 4 Diamonds, 3 Emeralds, 1 Lantern |
| Netherite | Diamond Backpack + 2 Netherite Ingots, 1 Nether Star, 2 Echo Shards, 2 Crying Obsidian, any Shulker Box |

## Controls

- **B** opens and closes the equipped backpack.
- **Toggle Backpack Lantern** defaults to **G**.
- Both keys can be changed under Options > Controls > Lime's Backpacks.
- Crouch right-click with a backpack to place it. Crouch right-click a placed backpack to pick it up.

## Optional integrations

- [Trinkets Updated](https://modrinth.com/mod/trinkets-updated) adds the wearable chest/back slot. It is licensed under the [MIT License](https://www.curseforge.com/minecraft/mc-mods/trinkets-updated/license).
- [LambDynamicLights](https://modrinth.com/mod/lambdynamiclights) adds dynamic lantern lighting. It is licensed under the [Lambda License](https://github.com/LambdAurora/LambDynamicLights/blob/1.21.5/LICENSE).

Lime's Backpacks links to their public APIs but does not bundle either mod's jar, code or assets. Install them separately if you want their features.
